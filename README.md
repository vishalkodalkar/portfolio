 # 🌐 Developer Portfolio

A modern and responsive personal portfolio built using **Next.js** to showcase my projects, skills, and development journey as a **MERN Full Stack Developer**.

---

## 🚀 Live Demo
🔗 (https://portfolio-delta-eight-52.vercel.app/)

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

---

## ✨ Features

- Modern and minimalist UI design
- Fully responsive across devices
- Project showcase section
- Developer journey & blog insights
- Contact form with API route
- Smooth animations and transitions
- SEO optimized pages
